# iE Landing

Адаптивный лендинг агентства разработки iE на Vite, React и TypeScript с русской
и английской версиями. Дополнительная серверная инфраструктура не требуется.

При обычной загрузке лендинг открывается брендированной заставкой. Если в системе
включено сокращение движения (`prefers-reduced-motion`), заставка пропускается;
для её принудительного просмотра откройте страницу с параметром `?intro=1`.
Переход к якорю или восстановленной позиции прокрутки выполняется после завершения
заставки.

## Запуск

```bash
npm install
npm run dev
```

## Команды

- `npm run dev` — сервер разработки с горячей перезагрузкой
- `npm run typecheck` — проверка TypeScript
- `npm run build` — production-сборка
- `npm run preview` — локальный просмотр production-сборки

Точка входа приложения — `src/main.tsx`, основной компонент страницы —
`src/App.tsx`.
