# iE Landing

Адаптивный лендинг агентства разработки iE на Vite, React и TypeScript с русской
и английской версиями. Дополнительная серверная инфраструктура не требуется.

## Запуск

```bash
npm install
npm run dev
```

## Команды

- `npm run dev` — сервер разработки с горячей перезагрузкой
- `npm run typecheck` — проверка TypeScript
- `npm run build` — production-сборка
- `npm run preview` — локальный просмотр production-сборки

Начальная точка приложения — `src/App.tsx`.
