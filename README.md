# Portfolio

Минимальная среда разработки на Vite, React и TypeScript без демонстрационного
интерфейса и дополнительной серверной инфраструктуры.

## Запуск

```bash
npm install
npm run dev
```

## Команды

- `npm run dev` — сервер разработки с горячей перезагрузкой
- `npm run typecheck` — проверка TypeScript
- `npm run build` — production-сборка
- `npm run preview` — локальный просмотр production-сборки

Начальная точка приложения — `src/App.tsx`.
